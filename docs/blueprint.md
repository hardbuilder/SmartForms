# **App Name**: FeedbackFlow

## Core Features:

- Form Builder: Create custom forms with various question types (e.g., multiple choice, text input).
- Poll Designer: Design and create polls for quick votes.
- Real-time Analytics: Display live results with basic charts and graphs, after the data gathering ends.
- Shareable Link: Generate shareable URL upon form creation, making the data collection readily accessible.
- AI Form Optimizer: Suggest improvements for questions and answer options using AI tool, to improve engagement

## Style Guidelines:

- Primary color: A vibrant blue (#29ABE2) to convey trust and reliability.
- Background color: A light gray (#F5F5F5) to ensure readability and focus.
- Accent color: An analogous teal (#2EC4B6), to highlight actions and key information without being distracting.
- Body and headline font: 'Inter', sans-serif, for a modern, clean, and highly readable interface.
